# روند — سیستم مدیریت (RAVAND Management OS)

نسخه‌ی ۱.۰ — فاز ۱ و ۲: ورود و نقش‌ها، داشبورد مدیریت و داشبورد عضو تیم، وظایف، پروژه‌ها، تیم، گزارش‌ها، تقویم شمسی، ساعت، یادآورها و گزارش تغییرات.

> این نسخه بدون Docker اجرا می‌شود و برای ویندوز یک نصب‌کننده‌ی EXE دارد.

## نصب یک‌کلیکی روی ویندوز

۱. فایل `Ravand-Setup.exe` را در همین پوشه پیدا کنید و روی آن دوبار کلیک کنید.
۲. ویندوز برای نصب پیش‌نیازها اجازه‌ی Administrator می‌خواهد؛ **Yes** بزنید.
۳. اگر PostgreSQL از شما رمز خواست، رمز کاربر `postgres` را وارد کنید. این همان رمزی است که هنگام نصب PostgreSQL انتخاب کرده‌اید.
۴. صبر کنید. بار اول چند دقیقه طول می‌کشد (نصب وابستگی‌ها و build).
۵. در پایان مرورگر خودش باز می‌شود: <http://localhost:3000>
۶. بار اول صفحه‌ی «راه‌اندازی اولیه» می‌آید؛ حساب مدیرعامل را همان‌جا بسازید.

نصب‌کننده این کارها را خودش انجام می‌دهد:

- اگر Node.js نباشد، Node.js LTS را با `winget` نصب می‌کند.
- اگر PostgreSQL 17 نباشد، آن را با `winget` نصب می‌کند.
- کاربر دیتابیس `ravand` و دیتابیس `ravand_os` را می‌سازد (اگر از قبل باشند، به‌روز می‌کند).
- فایل `.env` با رمز تصادفی و `AUTH_SECRET` امن می‌سازد.
- `npm install`، `prisma migrate deploy` و `next build` را اجرا می‌کند.
- میانبر **روند** روی دسکتاپ و در Startup ویندوز می‌سازد.
- برنامه را اجرا می‌کند و مرورگر را باز می‌کند.

فایل گزارش نصب: `install.log` در همین پوشه.

## اجرای روزانه

- روی میانبر **روند** روی دسکتاپ کلیک کنید یا `Ravand.exe` را اجرا کنید.
- آدرس: <http://localhost:3000>
- برای توقف سرور: `stop-ravand.cmd`

## نصب دستی (اختیاری، بدون EXE)

اگر خواستید مراحل را ببینید یا EXE کار نکرد، در PowerShell همین پوشه اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File installer\install.ps1
```

یا مرحله‌به‌مرحله:

```powershell
node scripts\init-env.mjs          # ساخت .env اگر نبود
# رمز postgres را هنگام اجرای نصب وارد کنید
npm install
npm run db:deploy
npm run build
npm start
```

پیش‌نیازها: Windows 10/11، Node.js 20 یا بالاتر، PostgreSQL 17. (نصب‌کننده هر دو را در صورت نبود نصب می‌کند.)

## رفع اشکال

| مشکل | راه‌حل |
|---|---|
| باز کردن localhost خطا می‌دهد | یک بار `Ravand-Setup.exe` را دوباره اجرا کنید. این کار وابستگی‌ها، جدول‌های دیتابیس و build را درست می‌کند. متن خطا و `install.log` را نگه دارید. |
| رمز PostgreSQL را نمی‌دانم | رمز کاربر `postgres` همان رمزی است که هنگام نصب PostgreSQL وارد کردید. اگر فراموش شده، از pgAdmin پسورد را بازنشانی کنید. |
| پورت 3000 اشغال است | `stop-ravand.cmd` را اجرا کنید یا در `install.ps1` مقدار `-Port 3001` بدهید. |
| صفحه‌ی سفید یا خطای دیتابیس | مطمئن شوید سرویس `postgresql-x64-17` در Services روشن است و `install.ps1` را دوباره اجرا کنید. |
| build خطا می‌دهد | پوشه‌ی `node_modules` و `.next` را پاک کنید و دوباره نصب‌کننده را اجرا کنید. |
| `npm` در PowerShell اجرا نمی‌شود | یک بار `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` را اجرا کنید. نصب‌کننده‌ی EXE خودش این محدودیت را دور می‌زند. |
| می‌خواهم از صفر نصب کنم | `Ravand-Setup.exe` را اجرا کنید. داده‌های موجود دیتابیس پاک نمی‌شوند. |

فایل‌های مهم:

- `.env` — رمز دیتابیس و `AUTH_SECRET` (هرگز در گیت نگذارید)
- `install.log` — گزارش کامل نصب
- `backups/` — پشتیبان‌های دیتابیس
- `prisma/migrations/` — تاریخچه‌ی ساختار دیتابیس

## پشتیبان‌گیری و بازیابی

```powershell
npm run backup
npm run restore -- ravand-20260101-120000.sql
```

پشتیبان در `backups/` ساخته می‌شود. این اسکریپت‌ها از ابزارهای خود PostgreSQL استفاده می‌کنند و به Docker نیاز ندارند. پشتیبان‌ها را مرتب روی یک دیسک دیگر هم کپی کنید.

## دسترسی از بقیه‌ی تیم (شبکه‌ی اداری)

```powershell
npm start -- -H 0.0.0.0
```

بقیه با `http://<IP کامپیوتر>:3000` وارد می‌شوند. در فایروال ویندوز فقط برای شبکه‌ی داخلی پورت 3000 را باز کنید. برای اینترنت/HTTPS، `COOKIE_SECURE=true` لازم است و هنوز مستند نشده است.

## به‌روزرسانی

```powershell
npm run backup
git pull
npm install
npm run db:deploy
npm run build
```

سپس `Ravand.exe` را دوباره اجرا کنید.

- `src/lib/health.ts` — قواعد «سلامت پروژه»

- `Ravand.exe` — اجرای روزانه
