# راوند — سیستم مدیریت (RAVAND Management OS)

نسخه‌ی ۰.۱ — فاز ۱ و ۲: ورود و نقش‌ها، داشبورد (دید مدیر و دید عضو تیم)، وظایف، پروژه‌ها، تیم، گزارش‌ها، تقویم شمسی، ساعت، یادآورها، گزارش تغییرات (audit).
ماژول‌های بعدی (استراتژی، مالی، فرصت‌ها، تصمیم‌ها، مرور هفتگی، خروجی AI، تجهیزات، اسناد) هنوز ساخته نشده‌اند.

> **وضعیت تست:** این کد روی سیستم توسعه‌دهنده نصب و اجرا نشده (آنجا اینترنت نبود). منطق تاریخ شمسی با `Intl` روی ۷۰ سال تست شده؛ بقیه‌ی بخش‌ها باید روی سیستم شما برای اولین بار اجرا شوند. هر خطایی دیدید، متن کامل را بفرستید.

## نصب روی کامپیوتر شخصی (ویندوز/مک/لینوکس)

پیش‌نیازها: [Node.js 20 LTS](https://nodejs.org)، [Docker Desktop](https://www.docker.com/products/docker-desktop)، [Git](https://git-scm.com).

باید روی ویندوز در پوشه‌ی پروژه، دستورها را **یکی‌یکی** و **بدون هیچ توضیحی** اجرا کنید (Docker Desktop باید باز و روشن باشد):

```
npm install
npm run setup:env
npm run db:up
npx prisma migrate dev --name init
npm run dev
```

- `npm run setup:env` فایل `.env` را با رمز و کلید تصادفی می‌سازد (اگر `.env` از قبل باشد دست نمی‌زند).
- بعد از `npm run dev` آدرس `http://localhost:3000` را در مرورگر باز کنید.

بار اول، مرورگر شما را به صفحه‌ی «راه‌اندازی اولیه» می‌برد؛ حساب مدیرعامل را آنجا بسازید. بعد از آن از بخش «تیم» اعضا را اضافه کنید.

برای اجرای دائمی (نه حالت توسعه): `npm run build && npm start`.

## گیت‌هاب (فقط کد، نه داده)

1. در GitHub یک مخزن **Private** بسازید.
2. در پوشه‌ی پروژه:
```bash
git init && git add . && git commit -m "RAVAND OS v0.1"
git branch -M main
git remote add origin https://github.com/<نام‌کاربری>/<مخزن>.git
git push -u origin main
```
`.gitignore` فایل `.env`، پشتیبان‌ها و فایل‌های آپلودشده را کنار می‌گذارد. **اطلاعات واقعی شرکت هرگز در گیت‌هاب نمی‌رود؛ فقط در پایگاه‌داده.**
بعد از اولین `npm install` فایل `package-lock.json` ساخته می‌شود؛ آن را هم commit کنید.

## پشتیبان‌گیری و بازیابی
```bash
npm run backup                              # backups/ravand-<زمان>.sql
npm run restore -- ravand-20260101-120000.sql
```
پشتیبان‌ها را به‌صورت منظم روی یک دیسک/فضای دیگر هم کپی کنید؛ پشتیبانی که فقط روی همان کامپیوتر است کافی نیست.

## به‌روزرسانی
```bash
npm run backup
git pull
npm install
npx prisma migrate deploy
npm run build && npm start
```

## دسترسی از بقیه‌ی تیم
- **همان شبکه‌ی اداری:** برنامه را روی یک کامپیوتر روشن بگذارید و با `npm start -- -H 0.0.0.0` اجرا کنید؛ بقیه با `http://<IP کامپیوتر>:3000` وارد شوند. (فایروال را برای پورت ۳۰۰۰ فقط در شبکه‌ی داخلی باز کنید.)
- **از بیرون/سرور:** حالت ریموت (سرور + HTTPS + `COOKIE_SECURE=true`) هنوز مستند و تست نشده است؛ مرحله‌ی بعد.

## نقش‌ها و دید هر نفر
| نقش | صفحه‌ی اصلی | دسترسی |
|---|---|---|
| مدیرعامل | کنترل مدیریت: موارد نیازمند توجه، بار کاری، پروژه‌های پرخطر | همه چیز، مدیریت کاربران، اطلاعات مالی پروژه |
| مدیر | همان دید مدیریتی | همه‌ی پروژه‌ها و وظایف، بررسی گزارش؛ مالی فقط با دسترسی صریح |
| عضو تیم / کارآموز | «روز من»: مهلت امروز، دیرکرد، موانع، یادآورها | فقط وظایف خودش و پروژه‌های خودش؛ وظیفه فقط برای خودش می‌سازد |
